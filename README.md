# Музейный квест — Дарвиновский музей × ГИМ

Статический сайт: чистые HTML, CSS и JavaScript, без сборщиков и зависимостей.

## Структура

```
index.html          разметка четырёх экранов
css/styles.css      токены (цвета, шрифты, скругления) + стили компонентов
js/questions.js     вопросы, варианты, правильные ответы и пояснения
js/app.js           логика: экраны, проверка ответов, подсчёт, звания
js/particles.js     фоновые частицы на <canvas>
```

## Запуск

Откройте `index.html` в браузере. В VS Code удобнее через расширение **Live Server**
(правый клик по файлу → *Open with Live Server*). Для публикации загрузите папку целиком
на любой статический хостинг.

## Как устроен квест

1. **Главная** → «Начать квест».
2. **Выбор музея** — маршруты в любом порядке, пройденный помечается «Пройден».
3. **Квест** — вопрос → выбор ответа → «Далее» → результат (зелёный — верно, красный — неверно,
   пропущенный правильный — «Правильный ответ») и пояснение → «Далее» → следующий вопрос.
   Кнопка «Назад» с пояснения возвращает к выбору ответа.
4. **Финал** — верные ответы, звание, статистика, стикерпак с промокодом, приглашение
   во второй музей.

## Где менять контент

| Что | Где |
| --- | --- |
| Вопросы, варианты, правильные ответы, пояснения | `js/questions.js` |
| Звания и пороги в процентах | `js/app.js` → `RANKS` |
| Доп. звания (Историк / Натуралист / Эрудит) | `js/app.js` → `BONUS` |
| Названия музеев, приглашения | `js/app.js` → `MUSEUMS` |
| Показ подсказки, минуты на карточке | `js/app.js` → `CONFIG` |
| Заголовок, описание, текст подсказки, стикерпак | `index.html` |
| Цвета, шрифты, скругления | `css/styles.css` → `:root` |
| Плотность и цвет частиц | `js/particles.js` → `CONFIG` |

### Формат вопроса

```js
{ q: 'Текст вопроса',
  a: ['Вариант А', 'Вариант Б', 'Вариант В', 'Вариант Г'],
  correct: [1],          // индексы: 0 = А, 1 = Б, 2 = В, 3 = Г; [0, 1] — несколько ответов
  explain: 'Пояснение' } // '' — без пояснения
```

## Подсчёт и звания

- Ответ засчитывается, если выбраны все правильные варианты и ни одного лишнего.
- Звание считается по сумме всех пройденных маршрутов: после одного — «промежуточное»,
  после двух — итоговое.
- После двух маршрутов добавляется доп. звание: больше доля верных в ГИМ — «Историк»,
  в Дарвиновском — «Натуралист», поровну — «Эрудит».
- Результаты хранятся в памяти страницы и сбрасываются при перезагрузке.

## Цветовая логика

Акцент маршрута задают переменные `--tint`, `--tint-fill`, `--tint-ink`, `--tint-soft`;
они переключаются атрибутом `data-museum` на `<body>`: `darwin` — зелёный, `shm` — оранжевый `#ED760E`.

## Адаптивность

Мобильный-первый макет, рассчитанный на экран телефона без прокрутки: размеры через `clamp()`,
сетки на `auto-fit`, кнопки не ниже 48 px, учитываются `env(safe-area-inset-bottom)`
и `prefers-reduced-motion`.
